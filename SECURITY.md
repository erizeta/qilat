# Security Policy

## Supported versions

Until v1.0.0, only the latest released minor version (v0.x) receives security fixes. Fixes are released as patch
versions and announced in GitHub Security Advisories and the [changelog](CHANGELOG.md).

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report them privately through GitHub Security Advisories:

**https://github.com/erizeta/qilat/security/advisories/new**

Please include:

- the affected version or commit;
- the protocol involved (HTTP/1.1, HTTP/2, HTTP/3) and whether TLS is used;
- steps or a minimal program to reproduce the issue;
- the impact you expect (for example request smuggling, denial of service, memory disclosure).

Reports are handled on a best-effort basis. You will be kept informed while a fix is prepared, and credited in
the advisory unless you ask otherwise. Please give us reasonable time to release a fix before disclosing the issue publicly.
