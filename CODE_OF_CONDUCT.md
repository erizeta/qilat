# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
All participants in issues, pull requests, discussions, and other project spaces are expected to follow it.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer, [erizeta](https://github.com/erizeta), on GitHub.
If the matter is sensitive, ask for a private channel first and do not share details publicly.

All reports will be reviewed and handled with respect for the privacy of everyone involved.
Enforcement follows the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
